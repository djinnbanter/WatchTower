Coming next — by situation
⚡

When the server lags

Separate farms from mods
  • Spot farms & chunk loaders — world pressure (entities, chunks) separate from “a bad mod”
▣

When you’re unsure about RAM or settings

Apply vetted settings safely
  • Safe guided fixes — apply vetted settings with preview & undo
✓

When you need to trust a restart

Understand outages · smarter advice
  • Why it really died — mod crash vs OOM vs panel/watchdog
  • Weekly digest — grade, crashes, disk trend, one useful next action
  • Smarter restart advice — suggest a maintenance window (panel still owns /stop)
▦

When mods need care

Quarantine · Safe updates · proof it helped
  • Jar quarantine — move aside (don’t delete) + Undo + restart reminder
  • Assisted Safe updates — verify, back up, swap; risky stays manual
  • Did that update help? — before/after performance
  • Tamper & secrets · CurseForge · shareable crash rules
◎

When players can’t join

Pack sync · first-hour confidence
  • Join clinic — failed join → exact mismatched jars → copy for Discord
  • Pin a known-good pack — freeze good list; banner + named diff on drift
  • First-hour sanity — Java, loader, client-only-on-server, deps — green/amber/red
◈

When the world itself is the problem

Farms · corruption · silent scripts
  • Farm / item-storm storytelling — not “buy more RAM”
  • Corrupt chunk playbook — region hint → stop → backup → repair (no silent wipes)
  • Silent script failures — KubeJS / datapack errors raised as Issues
⌘

When you need to act or ask for help

Safe actions · clean support handoffs
  • Live command bridge — preview safe triage (e.g. pause Chunky); confirm first
  • Player-safe explain + ops context — short vs admin detail; lag vs timeout (not analytics)
  • Optional anonymous diagnostics — opt-in, previewable, cooldown’d (off by default)
☰

For teams & checking in on the go

Co-admins · status · phone glance
  • Named admin accounts — per-person logins + who changed what
  • Public status page — “are we up?” without exposing the dashboard
  • Richer Copy for Discord · maintenance windows · mobile glance
↗

  • Fleet viewTPS, crashes, backups across many servers — proxy-aware
  • Alerts that reach youDiscord / webhook for crashes, lag, stale backups, pregen stalls
  • More platformsFabric + NeoForge 1.20.x — same dashboard & workflow

Not our job

We stay out of the way
  • Host panelsStart/stop, files, console → Pterodactyl / Crafty / AMP
  • Player analyticsRetention, GeoIP, leaderboards → Plan & similar
  • Client GPU crashesDoesn’t apply to headless dedicated servers
◆

Promises that don’t change

True no matter what ships
  • Your data stays yoursLocal-first · no telemetry · no log uploads by default
  • You’re in controlOpt-in network · preview & undo · no quiet world/mod edits
  • Ops, not surveillanceRun the server — don’t track players like analytics
  • Drop-in beside your hostA jar in mods/ — not a second control panel
