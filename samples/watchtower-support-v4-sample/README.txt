Watchtower support bundle
=========================

Privacy: text artifacts are redacted (secrets, IPs, UUIDs). Spark profiles are binary and unredacted.
Never includes dashboard-auth, world/playerdata, backups, or mod jars.

Sample v4 layout for docs/tests — not a live server capture.

How to read
-----------
Server issue:  PROBLEM.txt → report/brief.txt → evidence/crashes → evidence/logs → mods/
Watchtower bug: PROBLEM.txt → environment.json → watchtower/conf-redacted.conf → ops-cache
